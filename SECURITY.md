# Security policy

BlocTrust is a portfolio project and must use synthetic data only.

Do not open a public issue for a suspected vulnerability. Report it privately to the repository owner with reproduction steps, affected version, impact, and suggested mitigation. Do not include real resident, invoice, credential, or bank-account data.

Supported security properties are documented in `docs/threat-model.md`. Security claims are limited to controls covered by code, tests, or repeatable operational evidence.
